# Bakery Relational Database

A relational SQL database for a bakery, designed and implemented for the Database Design & Development course at Al Hussein Technical University (HTU).

## Scope

- Complete schema created with `CREATE DATABASE`
- Tables modeling **products, orders and inventory**
- Reporting structures for **sales and stock**

## Tech

SQL (MySQL)
